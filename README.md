# Realms of the Lost

This is for roblox stuido. I want to create a retro dungeon style game. I want it to be worlds based so semi open world. I want there to be a starting village, where you begin and the first two world dungeons there. Then once a players advanced enough they can move onto the next 'world' which is the next area of the world, here will be few small towns, overworld monsters and the next dungeon. I want this trend to continue until theres ten dungeons and 7-12 dungeons. Each area should be different location e.g plains, desert, cold but if a. few are similair its fine. I dont want it to be completely linear, some new areas of the world may have dungeons easier or harder than before, i want nothing to be physically blocked by  levels , just recommendations and difficulty that might keep for example a level 20 player out of alevel 500 dungeon , sort of like youd find in a game like sword art online. Lets start with this for now.
